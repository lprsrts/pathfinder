Pathfinder privacy notice

Notice version 1 · 25 November 2026

Pathfinder is a study tool that runs on your computer. This notice says what leaves your computer, where it goes, and how to change or erase it. Sharing usage data is optional: Pathfinder works the same if you say no.

Who is responsible

Mehmet Alper Sarıtaş, Karlsruhe, Germany (the developer). Contact: CONTACT_EMAIL.

What is sent, and only if you agree

WhatWhenContents
Usage eventsOnly if you tick “Usage events” and joined with an invite codeNumbers, yes/no flags and names from fixed lists: which step a turn was (planning, a check, a verdict…), how long it took, how many model calls and tool calls of each kind, the model’s name, whether the gate held a reply back and its score, whether a check was answered right or wrong and how many concepts it covered, permission answers, error codes, which app features you use, the app version, your operating system, and the conversation’s language. Each event carries a random install id, a random session id and the time to the minute. Never your messages, the model’s answers, file names, folder names, study topics or concept names. harness data show prints exactly what is waiting to be sent.
Threads you shareOnly if you tick “Threads you choose to share” and then type /share in a thread and confirm after seeing exactly what will be sentThat one thread as you saw it (your messages and Pathfinder’s), with file paths shortened to your study folder, plus an optional note from you.

The invite code and your name

Each invite code is made for one person. The developer keeps a list of which code he gave to whom, so the events from your install can be linked to you by him. The server itself stores only the install id and that label.

Things that go elsewhere regardless of the above

  • The model. Your messages and the files you work on go directly from your computer to the model provider you signed in with (for example OpenAI through “Sign in with ChatGPT”), under your own account and that provider’s terms. They do not pass through the developer’s server.
  • The shared gate. If you joined with an invite code and have no TypeSafe key of your own, the check that keeps a candidate’s answer hidden from you runs through the developer’s server: each check sends the candidate, the conversation since it was shown and the draft reply to the server, which forwards them to TypeSafe (the decision service) and returns the answer. The server does not store or log these contents; it only counts how many checks your install made per day, to keep within a daily limit. Set HARNESS_DECISION_PROXY=off to never use the shared gate.
  • Update checks. Once a day the app asks the server whether a newer version exists. That request carries only the app version. Set HARNESS_NO_UPDATE_CHECK=1 to turn it off.

Why, and on what basis

To find out what works and what breaks in Pathfinder for people other than its developer, and to improve it. The legal basis is your consent (Art. 6(1)(a) GDPR), given separately for usage events and for sharing threads. The data is not sold, not used for advertising, and not shared with anyone else. If any of it is ever to be used for research or a publication, you will be asked again first.

Where it is kept, and for how long

On the developer’s own server in Germany, reached through Cloudflare (which carries the encrypted connection and sees your IP address, as any web service’s network provider does). The server does not log IP addresses. Usage events are deleted after 12 months. Shared threads are kept until you erase them. The server is backed up daily, encrypted, to Cloudflare R2 storage in Western Europe; backups are kept for up to 12 months and are used only to restore the server after a failure, so data you erase leaves the backups within 12 months.

You can also ask the developer for a copy of your data, a correction or erasure, by email. Withdrawing consent doesn’t affect what was done before. You have the right to complain to a data protection authority, for example the Landesbeauftragte für den Datenschutz und die Informationsfreiheit Baden-Württemberg.

Changes

If what is collected changes, this notice gets a new version and Pathfinder asks you again before sending anything under it.

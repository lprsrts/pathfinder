# The Pathfinder icon

The cairn: trail stones settled by a rigid-body simulation in Blender, under a glass stone for what you were only told.

- `cairn.blend`: the settled scene.
- `build5.py`: builds, settles and renders the scene from parameters; `run.sh '<params>'` runs it headless (set `BLENDER` if Blender isn't in /Applications). Renders go to `out/`.
- The site's sizes are in `collector/public/icon-*.png`: the 1024 keeps Apple's macOS icon inset; 180, 32 and 16 are cropped to the tile.

Use it for a future app icon too.
